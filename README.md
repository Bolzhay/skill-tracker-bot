# Skill Tracker Bot

Telegram-бот для прокачки любого навыка: пиксель-арт, риторика, шахматы — что угодно. Бот строит дерево уровней под твой стартовый уровень, выдаёт задания, строго оценивает присланные пруфы (фото, голосовое, видео, текст) и ведёт прогресс: XP, серия дней, ранги, бейджи и сравнение «тогда vs сейчас».

Работает только на бесплатных моделях: OpenRouter и, по желанию, Google (Gemma). Данные лежат в Firebase Firestore, у каждого пользователя свои.

## Что умеет

Полный обзор с устройством, стеком и лимитами — в [PROJECT_OVERVIEW.md](PROJECT_OVERVIEW.md).

- **Дерево уровней.** Несколько моделей по очереди пишут, критикуют и дорабатывают план под твою самооценку и цель.
- **Задания.** Выдаются по команде, одно задание — одна цель. Антиповтор: локальное сравнение плюс проверка моделью. Каждое 6-е задание — «wildcard», нарочно ломающий шаблон. `/hint` даёт развёрнутую подсказку со ссылками на настоящие видео с YouTube.
- **Оценка пруфов.** Два независимых анализа фото, затем «скептик» выносит вердикт. Голос и видео расшифровываются локально (Whisper; у видео оценивается только звук). Засчитанная работа закрывает задание, незасчитанную можно пересдать.
- **Геймификация.** Левелап после 3 засчитанных заданий, XP, серия дней, ранги, бейджи.
- **Доступ.** Бот закрыт для чужих: владелец активирует его командой `/claim` и пускает людей через `/allow`.

## Быстрый старт

Понадобятся: Python (разработка и тесты — на 3.14), бот от [@BotFather](https://t.me/BotFather), проект Firebase и ключ [OpenRouter](https://openrouter.ai/).

**1. Firebase.** Создай проект и базу Firestore в режиме production. В «Project settings → Service accounts» сгенерируй приватный ключ и положи JSON в папку проекта. Правила базы должны запрещать всё — бот ходит через Admin SDK и правила обходит:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if false;
    }
  }
}
```

**2. Установка.**

```bash
python -m venv .venv
.venv\Scripts\activate            # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
```

**3. Настройки.** Скопируй `.env.example` в `.env` и заполни:

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `FIREBASE_CREDENTIALS_PATH` | путь к JSON сервисного аккаунта |
| `OPENROUTER_API_KEY` | ключ OpenRouter |
| `GEMINI_API_KEY` | необязательно: ключ [Gemini API](https://aistudio.google.com/apikey) из проекта **без** привязанной оплаты. Вторая бесплатная квота: у Gemma 14 400 запросов в сутки |
| `YOUTUBE_API_KEY` | необязательно: ключ YouTube Data API v3 из Google Cloud, для ссылок на видео в `/hint`. Бесплатно: 100 поисков в сутки |
| `CLAIM_CODE` | разовый код активации — любая длинная случайная строка |
| `TZ_OFFSET_HOURS` | необязательно: часовой пояс для серий, по умолчанию `5` |
| `WHISPER_MODEL` | необязательно: модель распознавания речи, по умолчанию `small` |

`.env` и ключ Firebase перечислены в `.gitignore` — не добавляй их в git.

**4. Запуск и активация.**

```bash
python -m bot.main
```

При первом запуске скачивается модель распознавания речи (один раз). Затем отправь боту `/claim <CLAIM_CODE>` — ты станешь владельцем. До этого бот не отвечает никому.

## Команды

| Команда | Что делает |
|---|---|
| `/new_skill` | создать скилл |
| `/task` | получить задание |
| `/hint` | развёрнутая подсказка к заданию |
| `/retry` | прислать пруф ещё раз |
| `/history` | последние задания |
| `/progress` | «тогда vs сейчас» (нужно ≥ 2 засчитанных фото) |
| `/profile` | скиллы, ранг, серия, бейджи |
| `/cancel` | отменить диалог |
| `/claim`, `/allow`, `/deny` | доступ, только владелец |

## Ограничения

- У бесплатного тарифа OpenRouter 50 запросов в сутки на весь аккаунт, а один цикл «задание → пруф» тратит 7–10. С ключом `GEMINI_API_KEY` после исчерпания лимита бот продолжает работать на Gemma от Google. Без него бот пишет о лимите и ждёт.
- Значения в `.env` главнее переменных среды ОС с теми же именами.
- Пока бот работает только локально (polling): он отвечает, пока запущен процесс. Облачный деплой требует платёжного аккаунта.
